# HTML Viewer & Mermaid Visualizer

ユーザーが入力したHTMLコードをリアルタイムでプレビュー表示、またはMermaid記法でテキストから図表を生成するWEBアプリケーションです。

## 特徴

- **2つのモード**: HTMLモードとMermaid図表モードを切り替え可能
- **リアルタイムプレビュー**: コードを入力すると即座にプレビューが更新されます
- **Mermaidビジュアライゼーション**: テキストから美しいフローチャート・図表を自動生成
- **プレビュー最大化**: 全画面でプレビューを表示可能
- **シンプルなUI**: 直感的で使いやすいインターフェース
- **レスポンシブデザイン**: PC・タブレット・スマートフォンに対応
- **安全性**: iframeのsandbox属性により安全にHTMLを表示
- **自動保存**: 入力内容とモードをLocalStorageに自動保存
- **サンプル機能**: ワンクリックでサンプルコードを読み込み可能

## 使い方

1. `index.html` をブラウザで開く
2. モード選択:
   - **HTMLモード**: HTMLコードを入力してプレビュー
   - **Mermaid図表モード**: Mermaid記法で図表を作成
3. 左側のテキストエリアにコードを入力
4. 右側のプレビューエリアに結果が自動表示されます

### モード

#### HTMLモード
HTMLコードをそのまま入力してプレビュー表示します。

#### Mermaid図表モード
Mermaid記法を使ってフローチャート、シーケンス図、ガントチャートなどを作成できます。

**例:**
```
graph LR
    A[開始] --> B[処理]
    B --> C[終了]
    style B fill:#4CAF50
```

複数の図を表示する場合は `---` で区切ります。

### ボタン機能

- **HTMLモード / Mermaid図表モード**: モード切り替え
- **クリア**: 入力内容をすべて削除
- **サンプルを読み込む**: 現在のモードに応じたサンプルコードを読み込み
- **最大化ボタン**: プレビューを全画面表示（ESCキーで閉じる）

## 技術スタック

- **HTML5**: アプリケーションの構造
- **CSS3**: スタイリング（グリッドレイアウト、グラデーション、アニメーション）
- **Vanilla JavaScript**: プレビュー機能とモード切り替えの実装
- **Mermaid.js**: テキストから図表を生成するライブラリ

## セキュリティ

iframeに`sandbox="allow-same-origin"`属性を設定することで、スクリプトの実行を制限し、安全にHTMLを表示しています。
