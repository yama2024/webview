# HTML Viewer

ユーザーが入力したHTMLコードをリアルタイムでプレビュー表示するシンプルなWEBアプリケーションです。

## 特徴

- **リアルタイムプレビュー**: HTMLコードを入力すると即座にプレビューが更新されます
- **シンプルなUI**: 直感的で使いやすいインターフェース
- **レスポンシブデザイン**: PC・タブレット・スマートフォンに対応
- **安全性**: iframeのsandbox属性により安全にHTMLを表示
- **自動保存**: 入力内容をLocalStorageに自動保存
- **サンプル機能**: ワンクリックでサンプルHTMLを読み込み可能

## 使い方

1. `index.html` をブラウザで開く
2. 左側のテキストエリアにHTMLコードを入力
3. 右側のプレビューエリアに結果が自動表示されます

### ボタン機能

- **クリア**: 入力内容をすべて削除
- **サンプルを読み込む**: サンプルHTMLコードを読み込み

## ファイル構成

```
/webview
├── index.html          # メインHTMLファイル
├── styles.css          # スタイルシート
├── script.js           # JavaScriptロジック
└── README.md          # このファイル
```

## 技術スタック

- **HTML5**: アプリケーションの構造
- **CSS3**: スタイリング（グリッドレイアウト、グラデーション）
- **Vanilla JavaScript**: プレビュー機能の実装

## セキュリティ

iframeに`sandbox="allow-same-origin"`属性を設定することで、スクリプトの実行を制限し、安全にHTMLを表示しています。
